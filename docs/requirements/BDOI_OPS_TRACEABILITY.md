# BDOI Operations (BRD-2) - Requirements Traceability

Every requirement of [`BDOI_OPS_BRD_SPEC.md`](BDOI_OPS_BRD_SPEC.md) with its status, the module that
builds it, the screens (routes) and endpoints (REST paths, bulk handlers, flow-in feeds, jobs) and
the tests that cover it. The module guide is [`docs/modules/OPERATIONS.md`](../modules/OPERATIONS.md);
its section 8 lists the parked items.

Statuses:

- **Built**: built and tested; nothing waits for BDOI.
- **Built, seam parked**: built and tested; a value, layout or integration BDOI has not given is a seam
  (port, parameter, configuration table or manual upload), named in the Notes column.
- **Superseded by BRD-4/5**: built in Operations as a seam, and the question behind it is now answered by
  the Collections BRD (BRD-4, [`BDOI_CLXN_BRD_SPEC.md`](BDOI_CLXN_BRD_SPEC.md) section 9) or the
  Accounting BRD (BRD-5, [`BDOI_ACCT_BRD_SPEC.md`](BDOI_ACCT_BRD_SPEC.md) section 8): OQ01, OQ02,
  OQ07, OQ38, OQ45. The replacement is designed there and not built in Operations. MKTID.001-009
  and MKTID.011 stay in Operations as built (BRD-4 section 9, OQ45).
